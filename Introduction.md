# Introduction

## What Is Python?

Python is a high-level, general-purpose programming language known for its readable syntax and broad ecosystem of libraries. It is widely used for web development, data analysis, automation, scripting, artificial intelligence, and more.

This guide walks you through installing Python on your computer, confirming the installation works, and resolving common setup issues.

## Why Install Python Locally?

Installing Python locally lets you:

- Run Python scripts and programs directly on your machine
- Use `pip` to install third-party packages and libraries
- Work with virtual environments for isolated projects
- Use Python-based tools such as Jupyter Notebook, Flask, or Django

## Software Requirements

Before installing Python, confirm your system meets the following requirements.

### Operating System Support

| OS | Minimum Version |
|---|---|
| Windows | Windows 10 or later (64-bit recommended) |
| macOS | macOS 11 (Big Sur) or later |
| Linux | Most modern distributions (Ubuntu 20.04+, Fedora, Debian, etc.) |

### Hardware Requirements

- At least 100 MB of free disk space (more if installing additional packages)
- 2 GB RAM minimum (4 GB or more recommended for data-intensive work)
- Internet connection (for downloading the installer and packages)

### Recommended Tools

While not strictly required to install Python, the following tools make development easier and are referenced elsewhere in this module:

- A code editor such as Visual Studio Code or PyCharm
- A terminal or command prompt
- Git, for version control (optional)

### Python Version

This guide covers the current stable release series of **Python 3**. Python 2 reached end-of-life in January 2020 and should not be used for new projects.
