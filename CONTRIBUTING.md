# Contributing

Thank you for contributing to this Python student project.

## 1. How to Report an Issue

If you find a problem:

1. Describe the issue clearly.
2. Explain what you expected to happen.
3. Explain what actually happened.
4. Provide any useful steps to reproduce the issue.

## 2. How to Suggest a Feature

To suggest a new feature:

1. Describe the feature clearly.
2. Explain why the feature would be useful.
3. Provide any relevant examples or details.

## 3. How to Create a Branch

Create a separate branch for your changes.

Use a clear branch name that describes your work.

Example:

```text
feature/add-new-function
```

## 4. How to Make Changes

1. Make your changes in the branch.
2. Keep the changes focused on the issue or feature.
3. Follow the basic coding guidelines below.
4. Review your changes before submitting them.

## 5. How to Test Changes

1. Run the Python project.
2. Check that the changed functionality works as expected.
3. Check that existing functionality still works.
4. Fix any problems found during testing.

## 6. How to Create a Pull Request

1. Push your changes to your branch.
2. Create a pull request.
3. Provide a clear title and description.
4. Explain what was changed.
5. Mention any relevant issue or feature request.

## 7. Basic Coding Guidelines

- Keep the code simple and readable.
- Use clear and meaningful names.
- Keep functions and sections focused.
- Add comments when they help explain the code.
- Avoid unnecessary changes.
- Test your changes before submitting them.
